These controls hold no state of their own. You pass the current value and a message, and your update changes the value. All of them tell screen readers their role and state.

The previews sit on a plain background. Put these controls on a solid or content background, and keep glass for buttons, slider thumbs and bars.

Switch

switch(theme, on, message). The knob slides when the value changes. Give it a label so a screen reader can say what it turns on.

{{example switches}}

Checkbox

checkbox(theme, label, checked, message) draws the label beside the box, and pressing the label toggles it too.

{{example checkboxes}}

Radio

radio(theme, label, selected, message). Build a group by calling it once per option, with selected true for the current one, and give each a key.

{{example radios}}

Slider

slider(theme, value, on_change) takes a value from 0 to 1 and calls on_change with the new one while the user drags. It also responds to the arrow keys, Home and End when focused, and screen readers can increment, decrement or set it.

{{example sliders}}

Segmented control

segmented(theme, options, selected, on_select) shows one of a few options at a time. It sizes itself to its labels. With a segment focused, Left and Right select the neighbouring one.

{{example segmented_control}}

Dropdown

dropdown(theme, options, selected, open, on_open, on_select) is a pop-up picker: a glass button that shows the selected option and opens a menu of all of them. Your app owns selected and open. on_open(true) is sent when the button is pressed, and on_open(false) when it is pressed again, when Escape is pressed, or when the user presses anywhere outside the menu. A press that closes the menu does nothing else, as on macOS. Up and Down move between the options once one has focus.

{{example dropdown_closed}} {{example dropdown_open}} {{rust}} Msg::Open(open) => self.open = open, Msg::Pick(index) => { self.size = index; self.open = false; } {{/rust}}

Disclosure

disclosure(theme, title, open, on_toggle, content) shows or hides its content when the heading is pressed. While it is closed the content is not in the tree at all. The heading tells screen readers whether the group is expanded or collapsed.
